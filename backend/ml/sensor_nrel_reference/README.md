# Experimental sensor power model

Selected from Random Forest, HistGradientBoosting and XGBoost using held-out experiments. See reports/sensor-nrel-model/REPORT.md and manifest.json for exact training/evaluation contracts.

Temperature-only laboratory estimates; no pressure or power-state substitution. Target is measured electrical watts at the same timestamp, not future kWh. Field accuracy is unverified. Credit DOE/NREL/ALLIANCE, DOI 10.7799/2440214; no endorsement implied. Keep SOURCE_LICENSE.txt with copies.
